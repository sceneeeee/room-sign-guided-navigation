# 首轮实验设计（预注册草案）

## 核心研究问题

- **视觉感知：** 现实室内门牌和方向指示牌能否在多距离、遮挡和角度下被稳定读取？
- **导航推理：** 只给出已观察门牌与少量拓扑信息时，方法能否比逐门搜索更有效地找到未知目标？

## 分开测量三类结果

| 层次 | 指标 | 注意事项 |
| --- | --- | --- |
| 感知 | 完整房间编号 Exact Match、未读出率、门牌检测召回率 | 包含失败样本；不只测试清晰正视照片 |
| 推理 | 目标搜索成功率、首次候选命中率、搜索步数/查看门数 | VLM 输入不可包含未来视频帧或答案 |
| 系统 | 端到端成功率、行走时间/距离、人工介入次数、推理延迟 | 固定同一起点、信息预算与终止条件 |

## 基线对照

1. **逐门搜索**：按照安全可走路线依次检查遇到的门，不按编号预测方向。
2. **局部编号启发式**：同走廊内至少有两条可信观察时，按局部编号趋势猜测下一段；遇到不确定信息弃权。这是候选基线，不代表建筑编号一定连续。
3. **VLM 高层推理**（计划中）：读入相同观测和拓扑信息，生成下一步观察策略和理由，不额外接触环境答案。

## 数据采集协议

- 拍摄实际楼道中不同距离、光照、门牌位置和模糊程度的图像；保留失败样本。
- 每条观测记录 `frame_id`、`timestamp_s`、`segment_id`、`side`、`text` 及方法来源。`confidence` 只保存模型实有的分数，未校准前不等同正确概率。
- 手持阶段可由操作员标注走廊分段和左右侧；这不是机器人自主定位。
- 记录在现场按算法建议移动的真实轨迹；不能用后验真实位置补全算法当时的输入。
- 人脸、个人身份信息或其他无关隐私应遮挡或删除；采集遵守场地要求。

## 成功判据（初步，可在实验前固定）

- M0：识别完整房间编号，得到可重复测量的精度和失败原因。
- M1：已观察地标能够结构化记录；确定性规则基线可以复现决策结果。
- M2：手机/USB 视频可以复用同一套视觉输入接口，避免重复记忆同一门牌。
- M3：人与推理模块闭环，按照相同任务、预算比较方法效果。
