# 首轮实验设计（视频流优先，预注册草案）

## 研究问题

1. 实际移动的视频中，能否及时、准确地识别门牌文字？运动模糊、视角和重复观测有何影响？
2. 在看不到目标房间时，基于已见门牌、指示牌与拓扑信息的搜索策略是否优于逐门检查？

## 阶段和指标

| 阶段 | 核心指标 | 约束 |
| --- | --- | --- |
| **M0 接入链路** | 实际采样率、处理耗时、网络端到端延迟、失败与断流次数 | `stream_every` 只是上传间隔；远程 OCR 耗时不是全链路延迟 |
| **M1 感知** | 门牌检测召回率、完整门牌 Exact Match、跨帧重复率、误读率 | 需保留遮挡、模糊、文字较小的失败帧 |
| **M2 推理** | 下一步建议的正确性、弃权次数、检查门数、搜索步数 | 只许读取当前已观察到的信息 |
| **M3–M4 系统** | 搜索成功率、实际行走距离/耗时、人工介入次数 | 各策略统一起点、信息预算和停止条件 |

## 对照方法

- **逐门搜索：** 按照实际可达顺序依次查看门牌。
- **局部编号规则：** 两条以上可比较的同走廊观测才根据局部顺序推测；不确定时弃权。
- **VLM 搜索策略（计划）：** 读取与规则方法同样的已知观测，输出下一步观察建议，不能获得尚未看到的门牌答案。

## 现场流程与数据

- M0：借 USB RGB 摄像头接到 MacBook；经 Gradio + SSH 将画面帧发送到远程 GPU，先核对取流/远端识别是否可用。
- M1：沿教学楼走廊缓慢行走，允许在门前停顿进行确认；保持真实时间戳和人工核验的真值。
- 拍照与录制视频仅用于**错误复现和回归测试**，不要求作为独立第一阶段。
- 为每个识别结果记录帧 ID、时间、文字原始输出、人工核验标签、代码版本与故障类别；未校准的模型分数不能视为正确概率。
- 手持实验可手工标注 `segment_id`、`side`，不将其解释为三维定位。
- 成员 B 现场可用 Codex 辅助修正代码，但必须审查修改并保留同条件复测日志，避免在对照实验中未记录地改算法。
- 不提交带有个人身份信息的现场视频到公开仓库；遵守教学楼采集规定。

## 阶段验收

M0 摄像头取流 + 远程 OCR + 返回结果；M1 门牌可信识别与跨帧去重；M2 地标记忆加下一步推理；M3 人机交互闭环；M4 基线对照评估。
