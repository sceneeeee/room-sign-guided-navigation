# M3.1 阶段验证与 PR 范围

2026-11-09，本分支在既有 detector/tracker、RapidOCR、M1/M2.4 和视觉控制器上完成真实录像的稀疏离线集成验证。实现和合成回归可公开审查；原录像、图像、模型权重及完整 OCR/回放日志留在本地 ignored 目录。

## 已验证范围

- 保留源 frame_id、整数 PTS、time_base 的完整 RGB 解码；缺失或不递增时间戳拒绝。
- 分离 actual detector 与人工审核框 oracle；后者要求可信图像绑定，不用 GT 文本替代新 OCR。
- detector → 短期 track → ROI 原始 OCR → M1 → M2.4 → M3 的事件落盘与模型无关的确定性回放。
- 空/错 OCR、模糊、歧义关联、目标丢失、重复/过期帧、显式 STOP 与模拟执行反馈的安全回归。
- M3.2 观察建议及非门牌上下文过滤原型：独立、可弃权，没有执行许可或物理门身份生成。

## 真实视频证据（本地实验）

| 项目 | 压缩 MP4 | 新提供的 raw MP4 |
| --- | --- | --- |
| 视频格式 | H.264、1280×720、8-bit BT.709 | HEVC Main10、1920×1080、BT.2020/HLG |
| 完整解码 | 2,499 帧 | 2,499 帧 |
| 21 帧成对采样的 door/sign 候选 | 41 / 11 | 50 / 18 |
| 非空 OCR ROI / 原始读数 | 9 / 33 | 13 / 50 |
| 独立门牌 OCR | LSS101、LSS119 | LSS101、LSS124、LSS119 |
| M3 动作 | 21 次 STOP_REOBSERVE | 21 次 STOP_REOBSERVE |

原视频 LSS124 首次在该采样集的真实 PTS 15.998333 秒自动读出（RapidOCR confidence=0.99997）。对应画面经独立边缘匹配和真实 PTS 对应后选取，相同帧编号不是匹配前提。两版权重、prompts、confidence=0.1、imgsz=640、CPU/4 Torch 线程及 OCR 设置一致。分辨率、编码与 HLG/SDR 同时变化，因此不能单独归因于某个质量因素。

另在原视频三个短片段按真实 PTS 约 2 FPS 推理：

| 片段 | 实际帧数 | door/sign 候选 | OCR 读数 |
| --- | ---: | --- | ---: |
| 0–6 秒，LSS101 阶段 | 13 | 25 / 8 | 39 |
| 12–20 秒，LSS124 阶段 | 17 | 48 / 15 | 28 |
| 76–83 秒，LSS119 阶段 | 15 | 25 / 16 | 91 |

45 帧实际推理产生 158 条读数，采样间隔 0.466667–0.5 秒；每段独立跟踪。M2 共 38 次 INSUFFICIENT_EVIDENCE、7 次 REOBSERVE，M3 全部 STOP_REOBSERVE。重新以过滤/建议策略处理同一输入是回放，不是新增模型推理。

这些实验复用 YOLOE `yoloe-11s-seg.pt`（SHA-256 `8e439445c87338b79d9ce21dec109f4621e26df67e94d26ea1a98c1e64dce3e3`）及 RapidOCR 3.10.0；Torch 2.14.1、Ultralytics 8.4.184、ONNX Runtime 1.31.0。完整参数、模型哈希、原始 PTS、失败案例和软件环境保存在各本地实验目录。

## 必须保留的限制

候选不是正确检测，OCR confidence 不是正确率。1080p 文件名不能证明相机原生来源；两个 MP4 内容对应也不能证明与原审核图像对应。原 MOV 和 20 张原审核关键帧仍缺失，可信 GT 绑定为零；没有 P/R/F1、实体门跟踪准确率或真实交互闭环成功率。

LSS124 段的一块墙面被模型误报为 door，并连续跟踪十帧。观察建议仍可能选中这种候选；十帧稳定性、较高分数和图像包含关系都不会将它升级为实体门。十帧合成安全回归和本地真实事件重放均检查无永久 ID、无自动 FOUND、无移动许可。

方向牌和海报原始文本、confidence、ROI 和来源继续留在事件输入，已知负面上下文在 M1 接纳 room Observation 前拒绝。v2 新增拆行方向牌的保守规则，v1/无策略旧日志保持原语义。无上下文的单房号海报、截断/模糊读数仍可能通过语法过滤；一般语义来源核验没有完成。

## PR 验收边界

本 PR 交付可复现的离线管线及受限建议原型，关联 Issue #5，**不关闭 Issue #5**。M2 规则与 M0 未重写，没有 VLM、SLAM、Nav2 或实时 UI 扩展。

M3.2 尚需可靠候选核验、自动选择/重选、门牌与实体门关联及独立执行授权。M3.3 尚需真实采集时钟、人在回路单门与多门现场验收。预录视频后续画面不会响应建议，模拟反馈仅用于契约测试。

复现入口见 [离线 CLI](m31-offline-replay.md) 和 [建议接口](m32-inspection-interface.md)。所有源码和合成测试可运行；真实感知复现需单独取得授权的私有视频与相同本地模型，事件回放无需模型。
